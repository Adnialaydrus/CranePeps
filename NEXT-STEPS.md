## ⚠️ Yang Perlu Anda Lakukan:

### 1. Tambahkan Logo (WAJIB)
```
📁 images/
  └── logo.png  ← TAMBAHKAN FILE INI
```

**Dari mana?**
- Gunakan logo yang Anda upload (gambar kedua)
- Atau gunakan file logo asli perusahaan
- Format: PNG, ukuran ~200-300px lebar

**Cara cepat:**
1. Buka file logo Anda
2. Save as PNG → nama: `logo.png`
3. Taruh di folder `images/`

### 2. Tambahkan Foto Crane (OPSIONAL tapi disarankan)
```
📁 images/
  └── crane-photo.jpg  ← Foto crane untuk section "Mengapa Pilih Kami"
```

**Dari mana?**
- Gunakan foto crane dari mockup Anda (crane kuning outdoor)
- Atau foto crane milik perusahaan
- Format: JPG, minimal 800x600px

### 3. Update Nomor WhatsApp

Cari dan ganti nomor `6281234567890` dengan nomor WA Anda di:
- `index.html` (ada 3 tombol WhatsApp)
- `hubungi-kami.html` (ada beberapa link)

**Format yang benar:**
- Gunakan kode negara: `62` (Indonesia)
- Tanpa angka 0 di depan
- Contoh: 0812-3456-7890 → 6281234567890

### 4. Test Website

**Di komputer:**
```
1. Double-click index.html
2. Buka di browser Chrome/Firefox/Edge
3. Test semua navigasi dan tombol
4. Klik tombol WhatsApp untuk test
```

**Di mobile (responsiveness):**
```
1. Buka Developer Tools (F12)
2. Toggle Device Toolbar (Ctrl+Shift+M)
3. Pilih iPhone/Android untuk preview
4. Test mobile menu dan semua fitur
```

### 5. Kustomisasi (Jika Perlu)

**Ganti email/telepon:**
- Edit footer di semua file HTML
- Edit halaman Hubungi Kami

**Ganti warna:**
- Edit `css/styles.css` bagian `:root`
- Ubah nilai `--primary-color`, dll

**Tambah konten:**
- Edit file HTML sesuai kebutuhan
- Tambah section baru jika perlu

## 🚀 Cara Upload ke Internet:

### Opsi A: GitHub Pages (GRATIS + Custom Domain)
1. Push ke GitHub repository
2. Enable GitHub Pages di Settings
3. Website live di `username.github.io/repo-name`

### Opsi B: Netlify (GRATIS + Super Mudah)
1. Buka netlify.com
2. Drag & drop folder `website-pp`
3. Langsung live dengan free domain!

### Opsi C: Hosting Biasa
1. Upload via FTP/cPanel
2. Pastikan `index.html` di root
3. Done!
