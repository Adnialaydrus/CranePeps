# Images Folder

Folder ini untuk menyimpan semua asset gambar website.

## 📸 File yang Dibutuhkan

### 1. logo.png (WAJIB)
- **Deskripsi**: Logo Sewa Crane Peps
- **Format**: PNG dengan background transparan
- **Ukuran Rekomendasi**: Lebar 200-300px
- **Lokasi**: `images/logo.png`
- **Sumber**: Logo sudah tersedia dari gambar yang Anda berikan

**Cara menambahkan:**
1. Simpan logo yang sudah Anda berikan (gambar kedua dengan crane kuning dan teks "Sewa CranePeps")
2. Pastikan format PNG dengan background transparan
3. Rename menjadi `logo.png`
4. Simpan di folder ini

### 2. crane-photo.jpg (OPSIONAL tapi disarankan)
- **Deskripsi**: Foto crane profesional untuk section "Mengapa Pilih Kami"
- **Format**: JPG atau PNG
- **Ukuran Rekomendasi**: Minimal 800x600px (landscape)
- **Lokasi**: `images/crane-photo.jpg`

**Sumber foto:**
- Gunakan foto crane dari mockup yang Anda berikan (crane kuning di lokasi outdoor)
- Atau gunakan foto crane milik perusahaan Anda
- Atau download dari stock photo (pastikan legal untuk digunakan)

**Catatan**: Jika foto tidak tersedia, section akan tetap terlihat baik, hanya imagenya saja yang tidak muncul.

## 📝 Tips Optimasi Gambar

### Untuk performa terbaik:

1. **Kompres gambar** sebelum upload
   - Online tool: TinyPNG, Compressor.io
   - Ukuran file logo sebaiknya < 100KB
   - Ukuran file foto sebaiknya < 500KB

2. **Gunakan format yang tepat**
   - Logo: PNG (untuk transparansi)
   - Foto: JPG (untuk file size lebih kecil)

3. **Ukuran yang sesuai**
   - Jangan upload gambar terlalu besar
   - Resize sesuai kebutuhan tampilan

## 🔧 Troubleshooting

### Logo tidak muncul di website
1. Pastikan nama file persis: `logo.png` (huruf kecil semua)
2. Pastikan file ada di folder `images/`
3. Clear cache browser (Ctrl+F5)
4. Periksa console browser untuk error

### Gambar terlalu besar/lambat load
1. Kompres gambar menggunakan tool online
2. Resize ke ukuran yang sesuai
3. Gunakan format JPG untuk foto (bukan PNG)
